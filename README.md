## About

I work on Odoo end to end: writing the modules, leading the reviews, and owning the projects
that put them in production. Most of that code lives in private client repositories, so this
profile shows the shape of the work more than the source.

The job splits three ways:

**Engineering** — Odoo modules in Python, XML and JavaScript on PostgreSQL. Dominican fiscal
localization (NCF / e-CF), accounting, inventory, sales and repair flows.

**R&D Manager** — code review, migration tooling and engineering standards across the team.
Most of my GitHub footprint is review, not authorship: I read considerably more code than I write.

**Odoo Project Director** — scoping, version upgrades and go-lives across 25+ client codebases,
on Odoo versions 13 through 19 and on Odoo.sh.
